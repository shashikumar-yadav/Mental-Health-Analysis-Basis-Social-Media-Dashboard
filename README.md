# Mental-Health-Analysis-Basis-Social-Media-Dashboard

# Overview
This Power BI dashboard provides a comprehensive analysis of how social media usage, screen time, exercise frequency, and stress levels correlate with sleep quality and overall mental well-being. 
Designed to support data-driven insights into behavioral health, the dashboard visualizes patterns that can inform personal habits, academic research, and wellness strategies.

# 🔍 Key Features

1. Sleep Quality Analysis
Explore how sleep quality varies with screen time, social media engagement, and exercise frequency.
2. Social Media Impact
Visual breakdown of time spent on platforms and its relationship with stress and sleep disruption.
3. Exercise Frequency Correlation
See how regular physical activity influences mental health indicators and sleep patterns.
4. Stress Level Visualization
Interactive charts showing stress levels across different demographics and behavioral habits.
5. Screen Time Distribution
Analyze daily screen time trends and their psychological implications.
6. Demographic Filters
Slice data by age, gender, and other attributes to uncover targeted insights.

# 📊 Technologies Used
- Power BI Desktop
- DAX & Power Query
- Custom Visuals & Bookmarks
- Data Modeling & Relationships
